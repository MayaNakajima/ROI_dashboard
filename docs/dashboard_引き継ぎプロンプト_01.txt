マーケティング本部ダッシュボードを作成しています。前のチャットが長くなったのでこのチャットで続きを行います。以下、引き継ぎ内容です。内容を把握してください。
成果物： marketing-roi-dashboard.html（outputs フォルダに保存済み）
ダッシュボード概要：

対象組織：マーケティング本部 / UN（企業ユニフォーム）/ SCH（スクール）/ MED（メディカル）/ IS（インサイトセールス）
主要機能：CV進捗（年間・YTD・当月目標）、CPA（費用÷CV）、CV→SAL→SQL→受注のコンバージョンファネル、月次チャート（セッション・CV・CPA・費用）、組織間比較テーブル、月別データ入力テーブル
データ永続化：localStorage＋JSONエクスポート/インポート（BOX共有用）
Excelファイル取込（SheetJS）：実績4ファイル（UN/SCH/MED/IS）・予実管理・コンテンツ本数管理
技術仕様：

純粋なHTML/JS単一ファイル（バックエンドなし）
Chart.js 4.4.0、SheetJS/xlsx 0.18.5（cdnjs）
localStorage キー：mktg_roi_v3
データモデル（org×月キーYYYY-MM）：{sessions, cv, sal, sql, jucyu, cost_mktg, cost_content, revenue}
CPA = 総費用 ÷ CV数。ROI指標は廃止済み
Excelファイルの列仕様（実績.xlsm）：

col[16]：YYYY-MM（月キー）、col[17]：SAL、col[18]：SQL（ISはSQL1）、col[19]：受注（ISはSQL2）、col[20]：受注（ISのみ）
IS SQL：col[18]またはcol[19]どちらかに値があれば1カウント 予実管理シート： オリジナルユニフォーム/スクール/メディカル/インサイトセールス → Row[3]=セッション、Row[14]=CV目標、Row[28]=マーケ費用 コンテンツ制作： 3枚目シート、col[5]〜col[16]が3月〜2月の月別費用、col[2]='合計額'行を使用 現在の課題・検討事項： BOXにHTMLを格納して複数人で使う運用を想定。

### 対象組織
マーケティング本部 / UN（企業ユニフォーム）/ SCH（スクール）/ MED（メディカル）/ IS（インサイトセールス）
※ マーケティング本部（ALL）は現在データなし

### 主要機能
- **表示期間フィルター**：開始・終了の2つの年月で期間指定
- **MQL進捗**：年間・期間累計・前年度/当年度別の目標達成率
- **コンバージョンファネル**：MQL→SAL→SQL→受注の累計と転換率
- **月次推移タブ**：数・単価・引き上がり率の月別テーブル＋グラフ
- **コンテンツROI**：予算÷制作本数を月別・組織別で表示
- **組織間比較テーブル**：期間集計での組織横断比較
- **月次グラフ**：CPA・セッション/MQL・費用・転換率・目標比較
- **月次データ入力テーブル**：手動入力対応
- **目標設定**：セッション(MAL)・MQL・SQLの月次目標を組織・年度別に設定
- **データ永続化**：localStorage（キー：`mktg_roi_v4`）＋JSONエクスポート/インポート（BOX共有用）

## 技術仕様

- 純粋なHTML/JS単一ファイル（バックエンドなし）
- Chart.js 4.4.0、SheetJS/xlsx 0.18.5（cdnjs）
- localStorageキー：`mktg_roi_v4`

### データモデル（`appData`）

```
actuals[org][YYYY-MM] = {
  sessions,           // セッション数（MAL）※予実管理から取得
  cv,                 // MQL数 ※実績ファイルB列CVフラグをC列CV日時の月で集計
  sal,                // SAL数 ※実績ファイルR列(col17)の日付の月で集計
  sql,                // SQL数 ※実績ファイルS列(col18)の日付の月で集計（ISはS/T列）
  jucyu,              // 受注数 ※実績ファイルT列(col19)/ISはU列(col20)の日付の月で集計
  cost_items[9],      // 費用①〜⑨（予実管理Row29〜37）
  cost_content,       // コンテンツ費用（単価×本数で自動計算）
  content_count       // コンテンツ制作本数
}

targets[org][YYYY] = {
  monthly_mql[12],      // MQL月次目標
  monthly_session[12],  // セッション月次目標（MAL）
  monthly_sql[12]       // SQL月次目標
}

costLabels[9]  // 費用項目名（デフォルト：費用①〜⑨）
```

### 表示期間
- 年度定義：3月〜翌年2月
- デフォルト：前年度3月〜当月（例：2025-03〜2026-06）
- KPI比較：選択期間 vs 1年前の同期間

## Excelファイル取込仕様

### ① 実績ファイル（.xlsm）― 組織ごとに4ファイル
★MQL/SAL/SQL/受注は実績4ファイルから直接カウントし、各ステージの日付列の月で集計する（実績ファイルが権威）。
1行目＝見出し。ヘッダー名でカラムを検索し、固定インデックスはフォールバック。

| 列 | 内容 | 集計 |
|---|---|---|
| col[1]（B列） | CVフラグ（3分類：①問い合わせ系／②資料ダウンロード系／③WP系） | ★値があれば1MQL＋CV種別分類 |
| col[2]（C列） | CV日時（回答日時, datetime） | ★MQLの月キー（YYYY-MM） |
| col[7]（H列） | 流入チャネル | ★mql_by_channelの分類。空白は不明（Unknown） |
| col[17]（R列） | SAL日付 | ★SALをこの日付の月でカウント |
| col[18]（S列） | SQL（IS以外）/ SQL判定①（IS） | ★SQLをこの日付の月でカウント |
| col[19]（T列） | 受注（IS以外）/ SQL判定②（IS） | ★受注(IS以外)／ISはSQL2の日付でSQL計上 |
| col[20]（U列） | 受注（ISのみ） | ★ISの受注をこの日付の月でカウント |

- シート名：UN=`流入チャネル別顧客一覧_7月以降完全ユニークではない`、他=`流入チャネル別顧客一覧_ユニーク`
- ISのSQL：col[18]またはcol[19]いずれかに日付があれば1カウント（日付のある列の月に計上）
- ISの受注はU列(col[20])のみ（T列col[19]はSQL2なので受注に計上しない）

### ② 予実管理ファイル（.xlsx）― 4シート構成

シート名マッピング：オリジナルユニフォーム→UN / スクール→SCH / メディカル→MED / インサイトセールス→IS

| 行（0始まり） | Excelの行番号 | 内容 |
|---|---|---|
| rows[1] | 2行目 | 年度ラベル（YYYY年度） |
| rows[2] | 3行目 | 月ヘッダー（3月〜2月） |
| rows[3] | 4行目 | セッション実績（MAL） |
| rows[12] | 13行目 | セッション目標（MAL） |
| rows[14] | 15行目 | MQL目標 |
| rows[21] | 22行目 | SQL目標 |
| rows[28〜36] | 29〜37行目 | 費用①〜⑨（9項目） |

### ③ コンテンツ本数管理ファイル（.xlsx）― 3シート目使用

| 列 | 内容 |
|---|---|
| A列（col[0]） | 制作種別（コラム記事・ホワイトペーパー等） |
| B列（col[1]） | 事業部（事業部名→org変換） |
| C列（col[2]） | 単価 |
| F〜Q列（col[5]〜col[16]） | 月別制作本数（3月〜2月） |

- **費用 = 単価 × 月別本数** で自動計算
- シート名から年度を自動検出（例：2026→3月〜翌2月）
- B列の事業部マッピング：メディカル→MED / インサイトセールス・IS→IS / 企業U・企業ユニフォーム→UN / 学生服・スクール→SCH

## コンテンツROI定義
**ROI = 総費用（マーケ費用計＋コンテンツ費用）÷ 制作本数**（月別・組織別）
※ コンテンツ本数管理ファイル取込時に自動計算

## 現在の課題・検討事項

- BOXにHTMLを格納して複数人で使う運用を想定
- データ共有はJSONエクスポート → BOX保存 → 他ユーザーがインポートの手順
- コスト項目名（費用①〜⑨）は現在汎用名称。将来的に予実管理ファイルのRow29〜37の行ラベルを読み込んで自動命名する改善余地あり
- マーケティング本部（ALLタブ）は組織別データの合算表示のため、個別データ取込後に反映される
