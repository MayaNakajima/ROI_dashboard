1. ダッシュボード概要
マーケティング本部の事業部別・月次KPIを一元管理するHTML単一ファイルのダッシュボード。BOXにHTMLを格納して複数人で共有利用する運用を想定。
対象組織
• マーケティング本部（ALL）— 独自KPIを自由設定（他4事業とKGI/KPIが異なるため、合算ではなく本部独自の指標を定義。ver.3〜）
• UN　— 企業ユニフォーム
• SCH — スクール
• MED — メディカル
• IS　— インサイトセールス
主要機能
• 表示期間フィルター（開始・終了の年月指定）
• MQL進捗：年間・期間累計・前年度/当年度別の目標達成率
• コンバージョンファネル：MQL→SAL→SQL→受注の累計と転換率
• 月次推移タブ：KPIテーブル・グラフ・コンテンツROI
• 組織間比較テーブル：期間集計での横断比較
• データ永続化：localStorage（キー mktg_roi_v4）＋JSONエクスポート/インポート
• Excelファイル一括取込：BOXファイル取込ボタンから実績4ファイル・予実管理・コンテンツ本数管理を取込

タブ	主な表示内容

月次推移テーブルの行構成
表示期間を年月で指定可能（デフォルト：当年度）。列＝年月＋年度合計、行＝以下の指標：
【年度合計列（ver.4〜）】
• 各月列の右側に、会計年度（3月〜翌2月）ごとの合計列を追加。
• 表示期間が複数年度にまたがる場合は、年度ごとに合計列を追加（例：2025-03〜2026-06表示なら「2025年度合計」「2026年度合計」の2列）。
• 合計は表示中の月だけでなく、その年度の全12ヶ月（3月〜翌2月）を集計（フィルタで一部月のみ表示していても年度全体の合計を表示）。
• マーケティング本部（ALL）の月次推移テーブルにも同様に年度合計列を追加。
【リード実績】
• MAL（セッション） / MQL（CV） / SAL / SQL / 受注
• MAL目標 / MQL目標 / SQL目標
【予算実績】
• 予算（実績）コラム / メルマガ / WP / 事例 / 広告 / Web運用 / コンサル / その他
金額表示：1円単位・桁区切り（例：¥1,234,567）
【コンテンツマーケ実績】
• MQL_Organic / MQL_Paid / MQL_Display / MQL_Email / MQL_Direct / MQL_Referral / MQL_OrganicSocial / MQL_Offline / MQL_Other
【CV実績】
• CV（問い合わせ） / CV（サービス資料DL） / CV（WPDL） / CV（合計）
コンテンツROIテーブル
• 列 = 年月 + 合計列
• 行 = 本数 / コンテンツ費 / マーケ費 / ROI（費÷本）
ROI = 総費用（マーケ費＋コンテンツ費）÷ 制作本数
CPA定義
• CPA = 期間合計費用（マーケ費＋コンテンツ費） ÷ 期間合計MQL（CV）数
• SQL CPA（ver.4〜）= 期間合計費用（マーケ費＋コンテンツ費） ÷ 期間合計SQL数
• いずれも年度区切りで計算（表示期間の集計値を使用）。MQL数またはSQL数が0の場合は「—」表示
• SQL CPAの表示箇所：①ダッシュボードKPIカード（「SQL CPA」カードを追加、計6枚）②コンバージョンファネル（期間累計サマリ＋ALL時の組織別テーブル）③組織間比較テーブル（CPA列の隣にSQL CPA列）④データ入力タブの表（「SQL CPA（自動）」列、SQL入力に連動して自動再計算）⑤月次CPA推移グラフ（CPA〈÷MQL〉とSQL CPA〈÷SQL〉の2系列を並列表示）

CSV（UTF-8）ダウンロード（ver.4〜）
• 月次推移タブの表右上「⬇ CSV（UTF-8）ダウンロード」ボタンで、表示中の月次推移テーブルのrowデータをそのままCSV出力（年度合計列を含む）。
• 事業部（UN/SCH/MED/IS）テーブル・マーケティング本部（ALL）テーブルの両方に対応（表示中のテーブルをそのまま出力）。
• 文字コードはUTF-8（Excelでの文字化け防止にBOMを付与）。各セルはダブルクォートで囲み、金額・桁区切りの「,」も安全に出力。
• ファイル名：月次推移_{組織}_{開始年月}_{終了年月}.csv（例：月次推移_UN_2026-03_2027-02.csv、本部は「本部」）。

8. データ共有フロー（BOX運用）
• データ入力/取込 → JSONエクスポート（ヘッダーボタン）
• エクスポートしたJSONをBOXに保存
• 他ユーザーがHTMLを開き → JSONインポート → データ反映
※ localStorageはブラウザ/端末ごとに独立するため、定期的なJSON共有が必要

10. 今後の課題・検討事項
• コスト項目名（費用①〜⑧）の自動命名：現在は固定ラベル（コラム/メルマガ/WP/事例/広告/Web運用/コンサル/その他）。将来的には予実管理ファイルの行ラベルを自動読込する改善余地あり
• マーケティング本部（ALLタブ）：現在は事業部データの合算表示のみ。個別データ取込後に反映される
• UNの実績シート名が他と異なる（流入チャネル別顧客一覧_7月以降完全ユニークではない）点に注意
• 年度をまたぐ期間指定をした場合、CPA・進捗は期間全体の合算となる（年度別分割表示は未実装）
